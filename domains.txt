# DNS 加速解析 - 域名清单 (V0.7)
# ------------------------------------------------------------
# 用法：
#   1. 一行一个域名，可保留 [分类] 标题。
#   2. 空行和 # 开头的行会被忽略。
#   3. 也可以直接粘贴 hosts 行（程序只取其中的域名）。
#   4. 修改本文件后，双击“一键解析DNS”即可重新生成结果。
#   5. 所有域名统一由站长之家 DNS 查询的多个节点投票决定 IP。
